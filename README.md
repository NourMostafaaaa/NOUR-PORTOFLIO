# Nour Moustafa — ASP.NET Core Portfolio

A responsive personal portfolio built with ASP.NET Core MVC (.NET 10), designed to present Nour's experience, selected projects, skills, education and contact information.

## Run locally
```bash
dotnet restore
dotnet run
```

## Deploy on Render
The repository includes a Dockerfile and Render Blueprint configuration. Create a **Web Service** using the repository and Docker runtime, or use the Blueprint flow from Render.

## Update the portrait
Replace `wwwroot/images/nour-moustafa.svg` with the approved portrait image and update the image reference in `Views/Home/Index.cshtml`.
